# 玄武岩构造环境判别系统

> 面向地球化学样品的智能构造环境判别工具

![系统工作流程](geodan-workflow.png)

## 一、研究背景

玄武岩是地球上分布最广、最具代表性的火成岩之一，其化学成分中保存了岩浆源区与所处构造环境的关键信息。从洋中脊到弧后盆地、从大陆裂谷到溢流玄武岩，不同构造背景下形成的玄武岩在主量元素与微量元素组合上展现出可识别的指纹特征。

长期以来，地球化学家依靠经验判别图（如 Pearce 图解、Wood 三角图、TAS 图等）对玄武岩进行构造环境归属。这些经典方法在二维或三维投影中划分类别区间，简单直观，但只能利用少数几种元素，难以处理高维元素组合中的非线性边界，对置信度也缺乏量化表达。

随着 GEOROC、PetDB、EarthChem 等大型公开地球化学数据库的积累，机器学习与深度学习方法开始在岩石分类与构造环境识别中发挥越来越重要的作用。借助卷积神经网络（CNN）等模型，可以从几十维元素特征中自动学习判别边界，并对每个样品同时输出预测类别与置信度，为人工复核提供量化依据。

## 二、系统任务

本系统的核心任务是：**给定一份玄武岩样品的主量元素与微量元素含量表格，自动判别每个样品所属的构造环境并输出置信度。**

具体而言，系统会完成以下工作：

- 解析用户上传的 CSV / XLSX 样品表，自动匹配元素列；
- 检查数据质量，对缺失值进行 KNN 或 MissForest 插补；
- 完成主量元素的无水归一化与分位数标准化；
- 调用本地 ONNX 模型批量预测构造环境（共 9 类）；
- 在数据预览、统计图表和地图三种视图下展示结果，并支持导出。

整个流程在浏览器本地完成推理，不依赖任何远程服务，便于研究人员处理未发表或敏感样品。

## 三、价值与意义

**对科研的价值**——本系统将经典构造判别图、机器学习模型与地图可视化整合为一站式工具，研究人员无需在不同软件之间反复切换。批量样品几秒钟即可得到一致、可复现的判别结果，特别适合野外样品初筛、文献数据库批量复核、以及在论文修订阶段快速核查样品归类。

**对教学的价值**——通过实时弹窗展示某个样品的主要元素含量、预测类别与置信度，并与世界地图上的实际位置关联，可以直观帮助学生建立"元素组合 ↔ 构造环境"的对应关系，比单纯讲解判别图更具沉浸感。

**对数据治理的价值**——系统内置缺失值过滤、重复样品去重、无水归一化、分位数标准化等流水线步骤，将"上传的原始表格"转化为"质量受控、可比较的数据集"，并在结果中保留中间字段供回溯，有助于建立可追溯的判别档案。

## 四、数据格式要求

系统接受 CSV 与 XLSX 两种文件，第一行必须为列名。模型需要 **36 个地球化学元素列**作为输入；此外 **LOI（烧失量）**列可缺省，缺省时按 0 处理。

**坐标列是可选的**，但只有提供经度与纬度时空间分布页才能渲染样品点。表头匹配是大小写不敏感的：

- 纬度：`LATITUDE` / `LAT` / `纬度` / `Y`
- 经度：`LONGITUDE` / `LON` / `LONG` / `经度` / `X`

**数据清洗规则**：

- 元素值为空、`-` 或非数字时视为缺失；
- 单行中缺失元素超过 20 个（约占 56%），认为信息量不足，整行剔除；
- 两行完全相同时只保留第一行，避免重复样品在统计中被双重计数；
- 太古代克拉通样品（依据文件名中的关键词识别）会被自动标记，参与策略回退。

## 五、工作流程

系统遵循"上传 → 整理 → 判别 → 复核与导出"四步流水线：

**1. 上传样品表格**
点击右上角"重新上传"或首页"开始使用"导入文件。系统会自动识别 36 个元素列与坐标列，并提示缺失列。

**2. 数据整理**
依次执行：缺失值插补 → 无水归一化 → 分位数标准化。整理后的数值会写回表格预览，方便逐行复核哪些字段参与了后续判别。

**3. 构造环境判别**
点击"开始预测"，本地 ONNX 模型按批次推理每个样品的 9 类构造环境概率分布，输出最高概率的类别标签及对应置信度。本步骤完全离线，不向外发送数据。

**4. 结果复核与导出**
进入"统计分析"或"空间分布"标签查看类别分布、置信度分布与地理分布；可按构造类型 / 置信度阈值筛选；通过侧栏按钮导出结果 CSV、空间结果 CSV、当前地图截图或全球底图。

## 六、可判别的九种构造环境

模型为每个样品输出唯一最高概率类别，**不会输出"未知 / 其他"类**。九种类别覆盖了现代玄武岩主要的构造背景：

- **洋中脊（SPREADING_CENTER）** —— 全球洋中脊系统及大洋扩张中心
- **大洋岛（OCEAN ISLAND）** —— 夏威夷、留尼汪等热点成因岛屿
- **洋底高原（OCEANIC PLATEAU）** —— 翁通爪哇、加勒比海等大火成岩省的海底部分
- **弧后盆地（BACK-ARC_BASIN）** —— 与俯冲带相关的弧后扩张盆地
- **岛弧（Island arc）** —— 大洋俯冲带形成的火山岛弧
- **洋内弧（Intra-oceanic arc）** —— 完全位于大洋板块之上的岛弧
- **大陆弧（Continental arc）** —— 大洋板块俯冲于大陆边缘形成的火山弧
- **大陆裂谷（CONTINENTAL_RIFT）** —— 东非裂谷、莱茵地堑等大陆张裂带
- **大陆溢流玄武岩（CONTINENTAL FLOOD BASALT）** —— 西伯利亚、德干等大陆型大火成岩省

地图与统计图表中的每种类别使用固定配色，配色方案在 `TECTONIC_COLORS` 常量中定义，保证不同视图之间的一致性。

## 七、插补策略：KNN 与 MissForest

地球化学数据库中的样品很少能完整覆盖所有 36 个元素，缺失值的处理策略直接影响下游预测的可靠性。系统提供两种可切换方案：

**KNN（默认）** —— 在已归一化的训练集中找最相似的若干邻居样品，用邻居的元素均值填补缺失。优点是速度快、稳定，对大多数现代玄武岩样品已足够。

**MissForest（两段式）** —— 先用 KNN 填补 → CNN 粗判构造环境 → 根据粗判标签调用对应环境的 MissForest 模型重新精插补 → 再次归一化 → CNN 正式判别。精度更高，但额外下载若干 JSON 模型文件，整体耗时较长，对元素缺失严重的样品提升明显。

**太古代回退**：如果文件名命中太古代相关关键词，MissForest 模式会自动回退到纯 KNN，原因是 MissForest 模型只用现代玄武岩训练，对太古代克拉通样品（如格陵兰 Isua、西澳 Norseman & Kambalda）缺乏代表性。

## 八、置信度与人工复核

置信度（Confidence）定义为模型对最高概率类别的输出概率，取值 0—100%。

经验上，**0.7（即 70%）** 是一个合理的高置信度阈值：

- **≥ 70%** —— 模型对该样品的归属较为确定，可直接采用；
- **< 70%** —— 模型在多个构造环境之间存在犹豫，建议结合地质背景、采样位置、稀土元素配分模式、同位素特征等额外信息进行人工复核。

空间分布页提供置信度阈值滑块，可以快速隐藏低置信度样品，专注于高可信度判别结果。在统计分析视图的 "需要复核 / Needs review" 指标卡中会显示需复核样品的数量。

## 九、空间分布视图

地图基于 [OpenLayers](https://openlayers.org/) 渲染，使用 **EPSG:4326（等距矩形）** 投影。相比常见的 Web Mercator（EPSG:3857）正方形世界图，4326 投影下世界天然呈 2:1 横向扁长，南北极区域不再被严重拉伸，更贴近真实地理比例。

**地图控件**（左上方按钮组）：

- 全图范围、全屏、当前视图截图；
- **EPSG:4326 全球底图导出**：通过 ArcGIS 服务端重投影，输出无白边的 4326 PNG，z3 → 4096×1935，z4 → 8192×3870，可选叠加样品点。仅支持 Esri 海洋底图与卫星影像。

**图层与筛选面板**（右上方）：

- 构造环境类型下拉、置信度阈值滑块；
- 点聚合、按类型着色、显示弹窗等显示模式开关；
- 图层管理：样品点 / 地貌图层等可独立开关。

**交互细节**：

- 所有浮动卡片（底图切换、图例、统计三件套、空间筛选面板等）均可拖动；
- 点击样品圆点会弹出该样品的预测类型、置信度、主要元素含量；
- 状态栏实时显示鼠标所在经纬度、当前缩放级别与底图名称。

## 十、导出

系统支持多种导出格式：

- **结果 CSV** —— 包含全部原始元素列以及附加的 `Predicted_Setting` 与 `Confidence` 两列；
- **空间结果 CSV** —— `INDEX / LATITUDE / LONGITUDE / Predicted_Setting / Confidence`，便于在 GIS 软件中继续分析；
- **地图截图** —— 当前视图的 PNG，包含底图与样品点；
- **全球底图** —— 服务器端重投影至 EPSG:4326 的高清世界 PNG，可叠加样品点；
- **结果摘要** —— 一段可粘贴到论文或邮件中的纯文本概述。

## 十一、数据隐私

**所有样品数据完全在浏览器本地完成解析、整理、推理与展示**，不会上传到任何远程服务器，适合处理未发表或具有保密要求的数据。

系统仅在以下场景访问外部公共服务：

- 加载 OpenLayers 底图瓦片（Esri、CartoDB）；
- 执行 EPSG:4326 全球底图导出时调用 ArcGIS 服务端重投影接口。

这些请求仅传输瓦片坐标参数，不携带任何样品元素含量数据。

## 十二、常见问题

**Q：为什么有样品没出现在结果里？**
A：可能原因包括：(1) 缺失元素超过 20 个被剔除；(2) 与表中已有行完全重复被去重；(3) 经纬度无效（导致地图不显示，但表格仍在）；(4) 置信度低于当前筛选阈值。

**Q：地图上为什么没有我的样品？**
A：检查表格是否包含 `LATITUDE / LONGITUDE` 列，且值为有效数字（非空、非 `null`、非字母）。也可能是当前置信度阈值过高把样品全部过滤掉了。

**Q：判别引擎加载失败怎么办？**
A：本系统首次加载 ONNX Runtime 与 CNN 模型时需要访问公网，请确认浏览器能访问 CDN。如果在企业内网中部署，可以将依赖文件打包到 `public/` 目录下离线提供。

**Q：可以离线运行吗？**
A：模型推理本身是离线的，但首次加载需要联网拉取依赖。一旦全部资源缓存到浏览器后，断网也能继续使用。

**Q：能否自定义构造环境类别？**
A：当前模型固定输出 9 类。如需扩展类别，需要重新训练 CNN 模型并替换 `public/model/` 下的权重文件。
