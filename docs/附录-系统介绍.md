# 附录　玄武岩构造环境判别系统简介

本系统是一套面向玄武岩主量与微量元素数据的构造环境判别工具，以网页形式提供，全部计算在浏览器本地完成，无需将样品数据上传至服务器，因而适用于尚未发表或较为敏感的数据。系统首页对功能与适用范围作了概要说明（图 1），用户可由此进入数据上传，或查阅帮助文档；页面同时标注了系统支持 CSV/XLSX 格式导入、批量数据清洗、缺失值检查、无水归一化以及结果查看与导出等能力，整体面向地球化学的批量筛查与构造判别研究场景。

![图1 系统首页](figures/fig1_home.png)

**图 1**　系统首页

数据导入通过上传对话框完成（图 2）。用户既可将文件拖入指定区域，也可点击选择本地的 CSV 或 XLSX 表格。系统可识别常见的地球化学样品表，共支持 37 项地球化学指标列；其中烧失量（LOI）允许缺失，其余缺失值会在后续预处理阶段自动填补，因此对原始数据的完整度要求较为宽松，便于直接使用来自不同来源的样品表。

![图2 数据上传对话框](figures/fig2_upload.png)

**图 2**　数据上传对话框

数据导入后，系统按既定流程依次完成列名识别、缺失值插补、无水归一化与分位数标准化等预处理，并在左侧以步骤清单的形式展示进度，最终进入构造环境判别与结果分析环节（图 3）。结果页以表格形式预览每个样品的主要成分及其预测的构造环境类型与置信度；表头中的化学式以规范的上下标形式显示，便于阅读。页面下方进一步以饼图和条形图直观呈现各构造环境类别的样品占比与数量分布，使整体判别结果一目了然；右侧栏则汇总了预处理选项、判别设置与结果导出入口，用户可在此选择插补方法并将判别结果导出为 CSV 表格。

![图3 判别结果展示页面](figures/fig3_results.png)

**图 3**　判别结果展示页面（数据预览与统计图表）

除统计视角外，系统还提供样品的空间分布视图（图 4）。该页面将带有经纬度信息的样品点叠加在世界底图上，并按预测的构造环境类型以不同颜色加以区分；点击任一样品即可弹出信息卡，显示其样品编号、预测类型、置信度、数据来源及主要元素含量。地图周边集成了构造环境占比、样品数量统计与区域分布概览等辅助图表，右侧的筛选与图层面板支持按构造类型、置信度阈值进行筛选，并可切换底图、投影方式与聚合显示等选项。借助这一视图，用户能够直观把握判别结果在全球范围内的地理格局，并可将地图截图或空间结果导出，用于进一步的分析与制图。
